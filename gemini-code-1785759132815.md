# Cross-Embudiment VLA to Planner Pipeline: Technical Architecture

This document outlines the concise, production-ready pipeline for executing zero-shot cross-embodiment task transfer from a source Vision-Language-Action (VLA) model (trained on a Franka Panda) to a target robot (such as a UR5e with a Robotiq85 gripper) within simulation environments like LIBERO. The architecture strictly decouples **Semantic Intent** from **Metric Feasibility**.

## 1. System Architecture Overview
The pipeline separates high-level task reasoning from low-level kinematic and collision-aware trajectory optimization:
* **Intent (VLA/GAM):** Ingests RGB images and language instructions, integrates temporal action chunks, and outputs a sparse, absolute 6D Tool Center Point (TCP) keypose in $\text{SE}(3)$.
* **Feasibility (CuRobo + Depth):** Ingests depth point clouds, target TCP keyposes, and the target robot's URDF to solve GPU-accelerated Inverse Kinematics and collision-free trajectory planning.
* **Execution (Controller):** Executes the resulting joint-space trajectory $q(\tau)$ and triggers gripper actuation.
